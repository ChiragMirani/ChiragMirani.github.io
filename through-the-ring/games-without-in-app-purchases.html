An ad-free casual game with no subscription

Flappy Tappy has no ads or subscription. It does offer an optional one-time purchase: it is not a game with no in-app purchases.

What stays free?

Endless Solo and duels with friends are free. Other duels include the first 100, then five each day. Check the current listing for purchase options and storefront prices.

How to compare casual games

  1. Read the free-play limits, not just the download price.
  2. Check whether ads appear between rounds or as optional rewards.
  3. Check whether a purchase renews.
  4. Distinguish offline Solo from online multiplayer.
