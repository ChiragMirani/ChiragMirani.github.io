# The Upanishads Reader

Published GitHub Pages app for:

https://chiragmirani.github.io/upanishads/

## What It Includes

1. 12 source-linked Upanishad works.
2. 330 sections from Max Mueller's public-domain Sacred Books of the East translations.
3. Plain meanings generated from the English translation.
4. Study relevance and theme tags for every section.
5. Sanskrit and generated transliteration where an aligned source is attached safely.
6. Mobile-first previous, next, random, and browse controls.

## Source Policy

1. English translations are linked to the Internet Sacred Text Archive source pages.
2. Original Sanskrit is shown only where an aligned source was attached safely.
3. Sections without verified aligned Sanskrit are marked `source_needed`; no guessed Sanskrit is inserted.
4. Generated transliteration is marked and should be verified before recitation.

## Search And Answer Readiness

1. Descriptive title and meta description.
2. Canonical URL.
3. Open Graph and Twitter card metadata.
4. JSON-LD `WebSite`, `CreativeWork`, and `FAQPage` data.
5. `robots.txt`, `sitemap.xml`, and `llms.txt`.
6. Visible answer content matching the structured data.
